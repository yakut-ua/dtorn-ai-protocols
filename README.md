# dtorn-ai-protocols

Авторские промпты, протоколы взаимодействия с LLM, прикладные скиллы и документированные кейсы.

## Разделы

- [Data](data/README.md): блог, ссылки и заметки.
- [Core](core/README.md): версии общеприменимых промптов.
- [Protocols](protocols/README.md): процедуры управления взаимодействием.
- [Skills](skills/README.md): инструкции выполнения конкретных задач.
- [Cases](cases/README.md): применение, проверки и ограничения.

## Принципы

Наблюдения отделяются от гипотез. Кейс указывает версии компонентов и условия проверки. Удачный пример не считается гарантией. Не публикуем ключи, персональные данные и приватные диалоги без согласия.

## Блог

Исходники публикаций: `data/_posts/`. Главная страница: `index.md`. Настройки: `_config.yml`.

Включение сайта: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Новая публикация: `data/_posts/YYYY-MM-DD-slug.md` с YAML-шапкой `layout: post`, `title` и `date`.
