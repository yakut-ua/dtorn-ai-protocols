# Protocols

Процедуры взаимодействия с моделью: калибровка фокуса, функционально-эмоциональный язык, перенос контекста и другие согласованные методы.

Структура: `<name>/README.md` — описание; `<name>/<version>.md` — текст протокола.

Паспорт: цель, условия запуска, шаги, наблюдаемые признаки результата, ограничения, совместимость и кейсы. Текстовые оценки не выдаются за чтение скрытых вычислений.

Пока опубликованных протоколов нет.
