# Core

Версии общеприменимых промптов, задающих общий режим работы.

Структура: `<name>/README.md` — описание; `<name>/<version>.md` — точный текст промпта.

Паспорт: назначение, подключение, версия, ограничения, совместимость и ссылки на кейсы. Старые версии сохраняются; кейсы ссылаются на конкретную версию.

Пока опубликованных ядер нет.
