# Cases

Документированное применение ядер, протоколов и скиллов.

Структура: `<name>/README.md` и при необходимости `<name>/materials/`.

## Паспорт кейса

1. Задача и происхождение материала: собственный эксперимент, публичная задача или согласованный клиентский кейс.
2. Дата, сервис, известное имя модели, инструменты и условия.
3. Точные версии компонентов.
4. Исходный вариант и изменение инструкции.
5. Прогоны и результаты, включая неудачные.
6. Выводы, неопределённость и ограничения.
7. Обезличенные материалы для повторения.

Не заявляем клиентский опыт там, где был самостоятельный эксперимент.

Пока опубликованных кейсов нет.
