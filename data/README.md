# Data

Материалы и публичный дневник проекта.

- `_posts/`: статьи блога в формате Jekyll.
- `notes/`: рабочие заметки; папка появится с первой заметкой.
- [links.md](links.md): ссылки с пояснениями.

## Шаблон публикации

```yaml
---
layout: post
title: "Название публикации"
date: YYYY-MM-DD HH:MM:SS +0300
---
```

Имя файла: `YYYY-MM-DD-slug.md`. После шапки пишется обычный Markdown. Публикации связываются с кейсами и версиями компонентов. Только публичные материалы: эта папка не является приватным хранилищем.
